# 整点自动播放声音（HTML + JavaScript）

这是一个简单的网页应用，用于在整点自动播放语音提示，并支持手动播放当前时间的语音播报。

---

## 功能说明

- **自动报时**：在每个小时的整点（如 9:00:00）自动播放“当前时间 X 点整”的语音。
- **手动播放**：点击“手动播放”按钮可立即播放当前实际时间的语音（如“当前时间 9 点 36 分”）。

---

## 技术栈

- HTML5
- CSS3
- JavaScript（使用浏览器内置的 `SpeechSynthesisUtterance` 实现文字转语音）
- 响应式设计（适配手机端与 PC 端）

---

## 使用方式

1. 将 `index.html` 文件部署到服务器或直接打开。
2. 首次使用请点击“手动播放”按钮以允许音频播放。
3. 系统将在每个小时的整点自动播放语音。

---

## 注意事项

- 若使用 `SpeechSynthesisUtterance`，部分浏览器可能需要用户交互后才能播放语音。
- 若需使用本地音频，请将音频文件放置在 `/audio/` 目录下，并修改 JS 中的路径。
